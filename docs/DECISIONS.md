## 2026-07-22 Спринт 5 — UI polish

### SQLite вместо PostgreSQL

**Вопрос:** какую БД использовать для Фазы 0?

**Решение:** SQLite (файл `dev.db`) вместо запланированного PostgreSQL.

**Почему:** ускорение локальной разработки, упрощение деплоя на этапе прототипирования, единая `.db` файл без настройки сервера.

**Последствия:** 
- `Prisma Json` тип недоступен → String с ручным JSON.stringify/parse
- `mode: 'insensitive'` в queries недоступен
- Миграция на Postgres потребует конвертации String → Json

### String вместо Json для body, attributes, snapshot

**Вопрос:** как хранить структурированные данные в SQLite?

**Решение:** `Scene.body`, `CodexEntry.attributes`, `Version.snapshot` как String (JSON-serialized).

**Почему:** SQLite Prisma-провайдер не поддерживает Json тип; String совместим с миграцией на Postgres позже.

**Последствия:** требует JSON.parse на read, JSON.stringify на write; граница сериализации в приложении, требует типизации.

### Centralize API URLs

**Вопрос:** как управлять API хостом при разных окружениях?

**Решение:** `API_BASE` константа из env или дефолт `http://localhost:3000`.

**Почему:** упрощить изменение при деплое, избежать дублирования жёстких URL.
