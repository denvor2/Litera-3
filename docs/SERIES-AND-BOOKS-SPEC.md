## 1. Модель данных

### Серия (Series) — было Project
**Определение:** Ряд книг, объединённых общим или переходящим сюжетом, локациями, персонажами и т.п. (сиквел, приквел, триквел и т.п.)

**Характеристики:**
- Одна серия может содержать несколько книг
- Кодекс (персонажи, локации, артефакты) привязан к серии и доступен всем книгам серии
- Контекст общий — персонаж, прописанный в Книге 1, может использоваться в Книге 2, 3 и т.д.
- История версий сцен — общая на уровне серии

### Книга (Book)
**Определение:** Отдельное литературное произведение, может быть частью серии или самостоятельной.

**Поля:**
- `title: string` — название
- `seriesId?: UUID` — привязка к серии (nullable → "Без серии")
- `genre?: string` — из фиксированного списка (15 жанров)
- `description?: string` — аннотация
- `synopsis?: string` — синопсис
- `plannedCharCount?: number` — плановый объём в символах
- `plannedAuthorSheets?: number` — плановый объём в авторских листах (1 а.л. = 40000 знаков)
- `order: number` — порядок в рамках серии (или в "Без серии")

**Изолированность:**
- Если книга БЕЗ СЕРИИ — её контекст полностью изолирован от остальных книг
- Цель: позволить писать отдельные произведения без привязки к универсуму

### Кодекс (CodexEntry)
**Текущая привязка:** `projectId` (будет = `seriesId`)  
**Изменение:** Все записи кодекса работают в рамках серии. Книги внутри серии видят весь общий кодекс. Книги без серии видят только свой кодекс (если такой будет).

## 2. UI/UX

### Левая панель (Sidebar) — новая структура

```
СЕРИИ И КНИГИ
├─ Серия 1
│  ├─ Книга 1
│  ├─ Книга 2
│  └─ + добавить книгу
├─ Серия 2
│  ├─ Книга 3
│  └─ + добавить книгу
├─ Серия 3 (пусто)
│  └─ + добавить книгу
└─ БЕЗ СЕРИИ
   ├─ Книга 4 (изолированная)
   ├─ Книга 5 (изолированная)
   └─ + добавить книгу
```

**Управление:**
- Клик на серию → показать её книги
- Клик на книгу → открыть рукопись этой книги
- "+" рядом с серией → добавить серию (уже есть, кнопка "+" рядом с СЕРИЯ)
- "+" внутри серии → добавить книгу в эту серию
- "+" в "БЕЗ СЕРИИ" → добавить книгу без серии

### Форма создания/редактирования книги

**Поля:**
```
Название: [_____________________]
Серия:    [Выпадающий список ▼]
          └─ Выбрать серию...
          └─ Серия 1
          └─ Серия 2
          └─ Серия 3
          └─ Без серии (опция внизу)

Жанр:     [Выпадающий список ▼]
          └─ Выбрать жанр...
          └─ Фантастика
          └─ Фэнтези
          └─ ... (15 жанров из BookCard)

Синопсис: [________________________]
          [________________________]

Описание: [________________________]
          [________________________]

Плановый объём:
  ☐ В символах: [_______] знаков
  ☐ В авт. листах: [_______] а.л. (= [__________] знаков)
  
[Отмена] [Сохранить]
```

**Логика:**
- Если "Без серии" выбрана → книга полностью изолирована
- Если выбрана конкретная серия → книга видит весь Кодекс этой серии
- Жанры — выпадающий список из 15 вариантов (из BookCard.tsx)
- Плановый объём может быть в символах или авторских листах (конвертация: 1 а.л. = 40000 знаков)

## 3. API endpoints

### Series (было Projects)
- `GET /api/series` — получить все серии с книгами и кодексом
- `POST /api/series` — создать новую серию
- `PUT /api/series/:seriesId` — обновить серию
- `DELETE /api/series/:seriesId` — удалить серию (soft delete)

### Books (с обновлениями)
- `GET /api/books?seriesId=...` — получить книги серии
- `GET /api/books?isolated=true` — получить "Без серии" книги
- `POST /api/books` — создать (с `seriesId?: null`)
- `PUT /api/books/:bookId` — обновить (включая жанр, плановый объём)
- `DELETE /api/books/:bookId` — мягкое удаление

### Codex
- Привязка к `seriesId` вместо `projectId`
- При удалении серии → удалить весь её кодекс

## 5. Особенности реализации

### Контекст книги
- **В серии:** Кодекс серии доступен всем книгам
- **Без серии:** Кодекс может быть только в рамках этой книги (если реализовывать)

### Порядок книг
- Внутри серии: `order` переиспользуется для сортировки
- В "Без серии": отдельная сортировка

### Гамбургер меню
- Кнопка "✨ Создать серию" — уже добавлена
- Кнопка "📖 Кодекс" — работает в рамках текущей серии

```

  Книга 2: "Встреча" (жанр: Приключения)
```
