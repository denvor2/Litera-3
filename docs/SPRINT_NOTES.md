## Сделано

### ✅ Пункт 9 — Drag-and-drop для сцен
- Перетаскивание сцены в другую главу меняет её chapter_id и order
- Перетаскивание сцены внутри главы меняет только order
- PATCH `/api/scenes/order` обновляет позицию сцены
- UI обновляется оптимистически, затем синхронизируется с backend
- **Статус:** Полностью реализовано и протестировано ✅

### ✅ Пункт 10 — Системная серия "Без серии"
- Добавлено поле `is_default` в PROJECT модель (Prisma)
- Миграция БД: `ALTER TABLE projects ADD COLUMN is_default BOOLEAN DEFAULT FALSE`
- DELETE `/api/projects/:id` проверяет `isDefault` и отказывает удаление (HTTP 403: "Cannot delete default project")
- Seed: default PROJECT с `isDefault: true` и названием "Без серии" создаётся для test user
- **Статус:** Backend полностью готов ✅

### ✅ Пункт 11 — Ссылка "Добавить серию"
- Текстовая ссылка "+ добавить серию" в серия-блоке Sidebar
- При клике открывается форма "Создать серию" в центральной панели
- Форма содержит поле "Название серии"
- POST `/api/projects` с `{ title }` создаёт новый проект
- После создания список обновляется и переключается на новый проект
- **Статус:** Полностью реализовано ✅

## Спринт 7б (см. ниже)

### ✅ Пункт 3 — Редактирование главы
- ✎ кнопка открывает форму в центре
- Поле: название главы
- PUT `/api/chapters/:chapterId` обновляет название
- Дерево обновляется после сохранения

### ✅ Пункт 4 — Редактирование сцены
- ✎ кнопка открывает форму в центре
- Поля: название, статус (draft/editing/done)
- PUT `/api/scenes/:sceneId` обновляет название и статус
- Форма отрывает центр, заменяя редактор

### ✅ Пункт 5 — Редактирование персонажей (Кодекс)
- ✎ кнопка на чипе персонажа открывает форму
- Поля: название, внешность, характер, цель/конфликт
- PUT `/api/codex/:entryId` обновляет name и attributes
- Аватар (инициалы) с --accent-soft фоном и --accent цветом

### ✅ Пункт 6 — Редактирование локаций (Кодекс)
- ✎ кнопка на чипе локации открывает форму
- Поля: название, описание
- PUT `/api/codex/:entryId` обновляет name и attributes
- Структура идентична персонажам, только полей описания вместо трёх атрибутов

### ✅ Пункт 7 — Автосохранение заметок
- Textarea в секции ЗАМЕТКИ привязана к selectedScene.notes
- Дебаунс 2 секунды после последнего изменения
- PUT `/api/scenes/:sceneId` с полем notes
- Сохранение синхронное, UI обновляется после ответа

### ✅ Пункт 8 — Корзина со счётчиком
- Бейдж рядом с "КОРЗИНА" показывает количество удалённых элементов
- Бейдж загружается при открытии секции
- Счётчик обновляется при восстановлении элементов
- Отображает только если count > 0

### ✅ Форма редактирования — структура и стили
- `.center-card` с max-width 520px, border и radius
- `.center-back` link «← Назад к сцене» над .head

- Подзаголовок `.subtitle` со строчными буквами (персонаж/локация)
- Поля `.field` с labels uppercase и --ink-muted цветом
- `.bc-actions` контейнер для кнопок: border-top, flex-end, [Отмена][Сохранить]
