# UI Правила доступности (WCAG AA)

## Размеры иконок и стрелок

**Правило:** Все интерактивные иконки, стрелки, символы должны быть размером **не менее 16px** (как строчная буква).

**Почему:** Люди с плохим зрением, возрастные пользователи, пользователи на мобильных устройствах должны видеть и нажимать на интерактивные элементы без напряжения.

**Применение:**
- Стрелки развертывания (аккордеон): `font-size: 16px` минимум
- Иконки кнопок (✎, 🗑, ↑, ↓): `font-size: 16px` минимум
- Все иконки в UI: базовый размер 16px, 18px, 20px, 24px

## Touch targets (сенсорные области)

**Правило:** Все нажимаемые элементы должны быть минимум **44x44px** (iOS/Android стандарт).

**Применение:**
- Кнопки: `min-height: 44px; min-width: 44px`
- Иконки кнопок: обёрнуты в контейнер 44x44px
- Чекбоксы, radio: 44x44px минимум

## Контраст (WCAG AA)

**Правило:** Все текст должен иметь контраст не менее **4.5:1** на обычный, **3:1** на большой текст.

**Текущие токены:**
- `--ink`: #232220 на #FFFFFF = 16:1 ✅ (отлично)
- `--ink-2`: #6B6862 на #FFFFFF = 5.5:1 ✅ (хорошо)
- `--ink-muted`: #9C9891 на #FFFFFF = 2.87:1 ❌ (плохо, нужно пересчитать)

## Focus indicators (видимость фокуса)

**Правило:** При Tab-навигации должен быть видимый outline.

**Применение:**
```css
button:focus, input:focus, a:focus {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

## Цветовая слепота

**Правило:** Не полагайтесь только на цвет для передачи информации. Используйте иконки, текст, паттерны.

**Примеры:**
- Статус сцены: не только цвет, но и текст "Черновик / Редактирование / Готово"
- Ошибки: не только красный, но и 🔴 иконка или текст "ошибка"

## Темная тема

**Правило:** Все цветовые токены должны работать в обеих темах (light/dark).

**Проверка:** Используйте `var(--ink)`, `var(--ink-2)`, `var(--border)` вместо жёстких цветов.
