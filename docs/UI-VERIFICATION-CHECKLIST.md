# Чек-лист сверки UI с мокапом — после Фазы 0

Источник истины: `design/mockup/index.html` + `design/mockup/UI-SPEC.md`. Этот файл — не новые требования, а **проверочный список**, вытащенный из уже описанного в UI-SPEC поведения, чтобы Архитектор/UI-ревьюер/дизайн-ревьюер (см. `docs/DOD.md`) могли пройтись по нему построчно после того, как все спринты Фазы 0 закрыты, а не держать всё в голове.

Прогонять целиком один раз — после последнего спринта Фазы 0, а не после каждого отдельного спринта (отдельные спринты уже проходят обычный DoD на своих кусках; этот чек-лист — финальная сверка того, что куски сложились в целостный интерфейс, который ведёт себя как единый мокап, а не как сумма частей).

Отмечать: ✅ реализовано как в мокапе / ⚠️ реализовано, но с отклонением (описать) / ❌ не реализовано.

## Левая зона
- [ ] Аккордеон эксклюзивный: открытие одной секции (Рукопись/Кодекс/Заметки/Корзина) закрывает остальные
- [ ] Нельзя закрыть последнюю открытую секцию — попытка закрытия возвращает её же открытой
- [ ] Переключатель серии/книги наверху: список книг серии, выбор книги перестраивает дерево «Рукопись» ниже, но не «Кодекс» (он общий на серию)
- [ ] На каждой строке (книга/глава/сцена/персонаж/локация) при наведении — ✎ и 🗑 (кроме серии — у неё только ✎, без 🗑)
- [ ] ✎ на книге/главе/сцене/серии/персонаже/локации открывает форму настроек в центре (не инлайн-переименование)
- [ ] 🗑 сразу отправляет элемент в Корзину без диалога подтверждения
- [ ] Под каждым списком — ссылка «+ добавить …» (сцена/глава/книга/персонаж/локация)
- [ ] Корзина показывает удалённые элементы всех типов из всей серии с кнопкой «восстановить»
- [ ] Выбранный элемент (текущая сцена в дереве, выбранная книга) — светло-голубая заливка, единая для всего интерфейса

## Центр
- [ ] Клик по сцене в дереве: сворачивает предыдущую развёрнутую сцену, разворачивает выбранную, скроллит к ней
- [ ] Клик по главе в дереве: скроллит к разделителю главы, не трогая развёрнутость сцен
- [ ] «Развернуть всю книгу» / «Свернуть до одной сцены» — переключатель над текстом, разворачивает/сворачивает весь поток
- [ ] Статус сцены редактируется инлайн (select) прямо в развёрнутой сцене
- [ ] POV, локация, целевой объём, переименование сцены — только через форму «Настройки сцены» (✎)
- [ ] Клик по подсветке упоминания (`.mention`) в тексте — открывает карточку Кодекса в центре
- [ ] Все виды центра (редактор / карточка Кодекса / карточка книги / настройки главы / настройки сцены / настройки серии / настройки AI-помощника / руководство) переключаются **без закрытия** левой и правой зон, гамбургер-меню, нижней полосы
- [ ] У каждой формы настроек — «← Назад» и кнопки Отмена/Сохранить
- [ ] Карточка Кодекса — поля редактируемые (не режим просмотра), блок «появляется в сценах» кликабелен и возвращает в редактор с разворотом нужной сцены
- [ ] Карточка книги: Серия и Жанр — выпадающие списки (не текст); Жанр — из классификатора Литрес

## Правая зона (AI-помощники)
- [ ] Ширина панели меняется перетаскиванием ручки за левый край (диапазон ~200–460px)
- [ ] Клик по чипу роли переключает активного помощника + типовые запросы + плейсхолдер поля ввода
- [ ] Клик по ⚙ у роли — открывает настройки этого помощника в центре, **не переключая** активную роль
- [ ] Клик по «+ свой» — открывает пустую форму «Новый помощник» в центре
- [ ] Строка масштаба запроса (Сцена/Глава/Диалог/Выделение) под чипами ролей — переключается кликом
- [ ] Выделение текста мышью в теле сцены автоматически переключает масштаб на «Выделение» и показывает цитату выделенного
- [ ] Форма запроса прижата к нижнему краю панели; область диалога — единственная растягивающаяся часть, ответы добавляются над формой
- [ ] Под заголовком — строка о контексте («текст этой книги + Кодекс серии»)

## Нижняя полоса
- [ ] Счётчики (слова / знаки с пробелами / а.л. / страницы) слева
- [ ] Прогресс-бар — только если у сцены задан целевой объём; если нет — бар не показывается вовсе
- [ ] Индикатор сохранения — цветная точка (зелёная/янтарная/красная) + текст, не только текст

## Верхняя панель
- [ ] Гамбургер открывает меню: Импорт, Экспорт, История версий/откатить, Руководство, Настройки
- [ ] «Руководство» открывает `docs/guide/how-to-write-a-book.md` (отрендеренным) в центре тем же механизмом, что и остальные виды
- [ ] «Полноэкранный текст» скрывает левую и правую зоны, оставляя центр и нижнюю полосу; повторный клик возвращает

## Мобильный (отдельный паттерн, не копия десктопа)
- [ ] Список сцен ↔ полноэкранный редактор одной сцены, переход по тапу и кнопке «назад»
- [ ] Тулбар форматирования прижат к низу экрана
- [ ] Плавающая кнопка «+» создаёт сцену
- [ ] Кодекс/заметки/Корзина/AI-помощники не показываются на мобильном в Фазе 0; карточка Кодекса — только через клик на подсветку упоминания

## Общее
- [ ] Мягкое удаление везде (`deleted_at`), ничего не удаляется физически при работе через UI
- [ ] Цветовая логика согласована: голубой только для «выбрано», зелёный/янтарный/красный только для статуса/сохранения, оранжевый только для упоминаний Кодекса — не перепутаны местами
