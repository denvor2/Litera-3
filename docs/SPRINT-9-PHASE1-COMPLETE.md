## Технические решения

### Проблема: Архитектурный разрыв
**Текущая система:**
- 1 Project = 1 Series (жестко)
- Все книги привязаны к 1 Project
- Невозможно иметь несколько серий в одном workspace

**Решение (Фаза 2):**
- Сделать Project → Series (переименовать или переосмыслить)
- Добавить `Book.seriesId` (nullable)
- Книга без серии: `seriesId IS NULL`
- Кодекс: `ProjectCodex` → `SeriesCodex`

### Данные, которые нужно мигрировать
```sql
-- Текущее состояние (не менять):
Books.projectId (всегда заполнено)

-- После миграции:
Books.seriesId (может быть NULL для "Без серии")
```
