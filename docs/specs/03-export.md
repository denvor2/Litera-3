# Модуль «Экспорт» — Фаза 0

Источник: п. 3.9 исходного ТЗ, сокращено до одного формата.

## Что входит
- Экспорт всей книги (все главы/сцены по порядку) в .docx
- Заголовки глав — стиль Heading 1. Заголовки сцен в экспортированный текст **не выводятся** — они служебные, только для навигации автора внутри приложения. Сцены внутри главы разделены пустой строкой, без флагов и настроек на этот счёт
- Экспортируется только `body` сцен со статусом `draft` и `editing` тоже включаются (не только `done`) — это экспорт черновика для чтения/печати, не публикационная выгрузка

## Что не входит
- .pdf/.epub/.fb2 — Фаза 2
- "Рукопись + библия мира" отдельным пакетом (3.9.3) — Фаза 2
- Полный экспорт/импорт проекта архивом (3.9.4) — Фаза 2, важно для бэкапов, но в Фазе 0 бэкап делается на уровне БД (см. PHASES.md, Фаза 1), не на уровне пользовательского экспорта
- Публикация в блоги/платформы (3.9.5) — не входит ни в одну текущую фазу, добавить в бэклог отдельно, если понадобится

## Технически
- Генерация .docx — на backend, синхронно для книг разумного объёма (MVP не ожидает сотни тысяч слов сразу — асинхронная очередь на воркерах, п. 8.2.5 исходного ТЗ, это Фаза 2, когда объёмы вырастут)
