# Модуль «Доска сюжета» — Фаза 2 (черновая спека, детализировать перед стартом спринта)

Источник: п. 3.2 исходного ТЗ.

Основа уже заложена в модели данных (PLOTARC/PLOTCARD, см. `../data-model.md`).

Открытые вопросы, которые нужно закрыть **до** старта спринта (не во время):
- Колонки доски — фиксированный список на структуру (3-акта/Путь героя/Save the Cat) или произвольные, которые создаёт пользователь? Исходное ТЗ (3.2.4) говорит "опционально накладываются как готовые колонки" — значит нужен и режим произвольных колонок по умолчанию, и шаблон как надстройка.
- Одна карточка сцены может быть в нескольких сюжетных линиях одновременно (PLOTCARD много-ко-многим со сценой) или строго в одной? В модели данных сейчас PLOTCARD.scene_id — одна связь на карточку; если нужна многие-ко-многим, менять схему заранее, не по ходу спринта.
