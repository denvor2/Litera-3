# LitStudio 2 — спецификации по модулям

Каждый файл в этой папке — спека одного модуля с acceptance-критериями. Клод Код и Архитектор при ревью работают с конкретным файлом модуля, а не с этим обзором и не с полным исходным ТЗ.

Порядок реализации = порядок фаз (`../PHASES.md`):

| Файл | Модуль | Фаза |
|---|---|---|
| 01-manuscript.md | Рукопись | 0 |
| 02-codex.md | Кодекс (базовый) | 0 |
| 03-export.md | Экспорт .docx | 0 |
| 04-plot-board.md | Доска сюжета | 2 |
| 05-outline.md | Конспект | 2 |
| 06-timeline.md | Таймлайн | 2 |
| 07-goals-insights.md | Цели и статистика | 2 |
| 08-ai-experts.md | AI-эксперты | 2 |
| 09-sync-offline.md | Синхронизация и офлайн | 3 |

Стек (зафиксирован для Фазы 0, см. обоснование в CLAUDE.md):
- Фронтенд: React + TypeScript + Vite, редактор текста — TipTap (обёртка над ProseMirror, легче голого ProseMirror, при этом при необходимости в Фазе 3 у TipTap есть готовая интеграция с Yjs — не придётся менять движок редактора)
- Backend: Node.js + Fastify + Prisma ORM
- БД: PostgreSQL
- Экспорт: docx (Фаза 0), остальное — Фаза 2

Всё, что не зафиксировано явно здесь или в CLAUDE.md, Клод Код решает сам в рамках спринта без вопросов — и это решение фиксируется в коде/комментарии, чтобы Архитектор мог его проверить постфактум.

## Визуал
`design/mockup/index.html` — интерактивный макет Фазы 0 (три экрана: рабочее пространство, режим письма, карточка Кодекса). `design/mockup/UI-SPEC.md` — привязка макета к пунктам спек, обязательна к прочтению перед версткой UI в каждом спринте, который трогает интерфейс. UI-ревьюер (`.claude/agents/ui-reviewer.md`) и дизайн-ревьюер (`.claude/agents/designer.md`) сверяют реализацию именно с этими двумя файлами.
