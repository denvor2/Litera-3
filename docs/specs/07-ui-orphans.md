## Техдолг

### Баг #12 (старые body-строки):
- Seed-данные хранят `body` как JSON-строку
- TipTap не может распарсить строку как документ
- Новые сцены хранят как объект (работают)
- **Решение:** миграция конвертации в Prisma или SQL скрипт

### Дизайн-несогласованность:
- CodexPanel/CodexForm/CodexList используют Material-палитру
- Требует переписать на авторскую палитру

### Тёмная тема (SceneEditor):
- Жёсткие светлые цвета в CSS
- Требует замены на переменные
