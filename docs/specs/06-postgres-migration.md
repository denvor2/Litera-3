# Sprint 6 — Миграция на PostgreSQL и стабилизация Фазы 0

## Цель
Привести реализацию в полное соответствие со спекой Фазы 0: PostgreSQL (вместо SQLite), нативный Json тип, soft-delete, экспорт в docx/fb2/pdf, доступность.

## Пункты

### 1. Миграция на PostgreSQL — исправление отклонений от спеки

**1.1 Схема Prisma**
- Сменить провайдер: `provider = "postgresql"` (вместо `"sqlite"`)
- Восстановить Json типы: `body Json`, `attributes Json`, `snapshot Json` (вместо String)
- Создать миграцию: бэкапить текущие данные, конвертировать String→Json, применить миграцию
- Env-файл: `DATABASE_URL="postgresql://user:pass@localhost:5432/litstudio"`

**1.2 Удаление в корзину (soft-delete)**
- Добавить поле `deleted_at DateTime?` в BOOK, CHAPTER, SCENE, CODEXENTRY
- Все `findMany` запросы: фильтр `where: { deleted_at: null }`
- DELETE запросы: `update { deleted_at: now() }` (мягкое удаление)
- GET `/api/trash` → возвращает удалённые элементы (сцены, главы, книги, codex)
- PUT `/api/trash/:type/:id/restore` → `deleted_at = null`

**1.3 Поиск**
- Восстановить `mode: 'insensitive'` в search queries (PostgreSQL поддерживает)
- Убрать ручное приведение к нижнему регистру в поиске по body

### 3. Доступность (WCAG AA)

**3.1 Контраст**
- `--ink-muted` и другие низконтрастные тексты: либо затемнить, либо использовать на крупных размерах (14px+)
- Проверить все на contrast ratio ≥ 4.5:1

**3.2 Размеры шрифтов**
- Минимум 12px для интерактивных элементов
- Кнопки: ≥ 44x44px touch-таргет

**3.3 Фокусные индикаторы**
- Видимый outline на всех интерактивных элементах при Tab-навигации
- Цвет фокуса: контрастный на фоне

### 4. Экспорт книги (docx, fb2, pdf)

**4.3 PDF**
