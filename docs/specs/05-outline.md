# Модуль «Конспект» — Фаза 2 (черновая спека)

Источник: п. 3.5 исходного ТЗ.

- Линейный текстовый план по главам/сценам, независимый от Доски сюжета
- Разворачивание пункта конспекта в полноценную сцену на «Рукописи» — при разворачивании создаётся SCENE с телом = тексту пункта конспекта как стартовым черновиком

Открытый вопрос: конспект — это отдельная сущность в БД (OutlineEntry) или просто представление уже существующих SCENE с пустым/кратким body? Решить перед спринтом — от этого зависит модель данных.
