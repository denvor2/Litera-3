# Спринт 7в — Продвинутые функции Sidebar

## Пункты 9-11 из плана

### 9. Drag-and-drop для сцен
- Перетаскивание сцены в другую главу меняет её `chapter_id` и `order`
- Перетаскивание сцены внутри главы меняет только `order`
- Перетаскивание главы меняет её `order` в книге
- Backend: PUT `/api/scenes/:sceneId` с полями `chapter_id, order`
- Backend: PUT `/api/chapters/:chapterId` с полем `order`
- UI обновляется оптимистически, потом синхронизируется с backend

### 10. Системная серия "Без серии"
- При создании пользователя автоматически создаётся PROJECT с `title = "Без серии"`
- Флаг `is_default = true` (добавить в модель данных)
- Эта серия не может быть удалена через UI
- При удалении серии, если это не default — OK
- При попытке удалить default — показ ошибки или скрытие кнопки удаления

**Backend изменения:**
- Добавить поле `is_default` в PROJECT (nullable boolean)
- Миграция: `ALTER TABLE project ADD COLUMN is_default BOOLEAN DEFAULT FALSE`
- Seed: автоматическое создание default PROJECT при создании USER
- API: при DELETE /api/projects/:id — проверка `is_default` и отказ удалить

### 11. Ссылка "Добавить серию"
- Под списком книг (после "+ добавить книгу") — текстовая ссылка "+ добавить серию"
- При клике открывается форма создания новой серии в центре
- Форма: поле "Название серии"
- POST `/api/projects` с названием
- После создания обновляется список серий (если он есть в левой панели)

## Изменения модели данных
```prisma
model Project {
  // ... существующие поля
  is_default  Boolean?  // Системная серия, не удаляется
}
```

## Backend требования
- POST `/api/projects` с `title`
- PUT `/api/projects/:id` с `title`
- DELETE `/api/projects/:id` — проверка `is_default`, отказ если `true`
- Seed: создание default PROJECT для каждого USER

## UI требования
- Ссылка "+ добавить серию" как текстовая ссылка (не кнопка)
- Форма создания серии в центре
- После создания вернуться в список
