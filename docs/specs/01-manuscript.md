# Модуль «Рукопись» — Фаза 0

Источник: п. 3.1 исходного ТЗ, сокращено до MVP.

## Иерархия
Книга → Глава → Сцена. Без «Бита» (это Фаза 2, если понадобится).
Одна Книга = одна Рукопись в MVP (Проект как контейнер серии — Фаза 2+, но модель данных уже это закладывает, см. `../data-model.md`).

## Карточка сцены — обязательные поля
- title: string, обязательно, до 200 символов
- status: enum `draft | editing | done` — по умолчанию `draft`
- pov_character_id: ссылка на CODEXENTRY типа `character`, опционально (может быть пусто)
- word_count: **не редактируется вручную**, пересчитывается автоматически при каждом сохранении текста сцены
- body: сам текст сцены (rich text, хранится как TipTap JSON, не как HTML-строка — так проще потом версионировать и парсить на упоминания сущностей)

## Drag-and-drop
- Перетаскивание сцены меняет её `order` внутри главы и/или её `chapter_id`, если сцену перенесли в другую главу
- Перетаскивание главы меняет её `order` внутри книги
- При параллельных изменениях порядка (два запроса подряд) — последний записанный порядок побеждает; конфликт-резолюшена в MVP нет (это Фаза 3)

## Режим письма
- Полноэкранный: скрывает сайдбар и панели, оставляет заголовок сцены + текст + счётчик слов
- Выход по Esc или явной кнопке
- Таймер/спринты — **не входят в Фазу 0**, отложить

## Автосохранение
- Дебаунс 2 секунды после последнего изменения текста, либо сохранение при потере фокуса редактора — что наступит раньше
- Индикатор состояния сохранения (сохранено / сохраняется / ошибка) виден пользователю всегда
- При ошибке сохранения — не терять несохранённый текст локально в памяти клиента до следующей успешной попытки; повторять попытку автоматически

## Версионирование (упрощённое для Фазы 0)
- Снапшот текста сцены сохраняется в таблицу VERSION при каждом переходе статуса сцены (draft→editing, editing→done) и не чаще одного снапшота в 10 минут при обычном автосохранении
- Просмотр списка версий сцены и восстановление любой — восстановление создаёт новую точку в истории, не удаляет промежуточные

## Инлайн-подсветка упоминаний (3.1.6, упрощено)
- MVP: точное совпадение полного имени CODEXENTRY (без словоформ/склонений) подсвечивается в тексте сцены
- При наведении/клике — всплывающая карточка с именем, типом и кратким описанием сущности
- Морфологический разбор (склонения, частичные совпадения) — Фаза 2

## Заметки на полях (3.1.7) — Фаза 0 упрощённо
- Одно текстовое поле "заметки" на сцену (не привязанное к конкретному месту в тексте — привязка к фрагменту текста это Фаза 2, вместе с Comment)

## Явно не в Фазе 0
- Проверка грамматики/стиля (3.1.8) — отдельная спека будет добавлена перед стартом Фазы 2, зависит от выбора движка (LanguageTool или аналог)
- Биты, таймер спринтов, привязанные к фрагменту комментарии
