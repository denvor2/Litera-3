# Модуль «AI-эксперты» — Фаза 2 (черновая спека)

Источник: п. 3.8 и 3.11 исходного ТЗ.

Изолированный AI-сервис — прокси к внешнему LLM API, полностью отключаемый (3.11.9). Не влияет на работу остальных модулей, если выключен/недоступен.

Открытые вопросы перед стартом спринта:
- Какой LLM-провайдер и через какой API — фиксируется отдельно, до спринта, не решается Клод Кодом на лету (ключи/квоты — вопрос владельца проекта)
- Контекст "вся книга или вся серия" (3.8.3) — это буквально весь текст в промпт, или релевантная выборка (RAG)? При объёме в сотни тысяч слов буквальная передача всего текста не сработает по лимитам контекста — нужен явный выбор подхода перед реализацией
