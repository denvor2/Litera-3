# Спринт 8б — Правая зона: AI-помощники

## Задача
Реализовать интерактивную правую панель с переключением ролей AI-помощников, масштабом запроса, диалогом и полем ввода.

## Требования (из UI-VERIFICATION-CHECKLIST, пп. 20–27)

### 20. Ширина панели перетаскиванием
✅ Уже реализовано (200–460px). Оставить как есть.

### 21. Клик по чипу роли переключает помощника
- Чипы: Соавтор, Редактор, Критик, Читатель (+ плюс свой)
- Клик по чипу: активирует эту роль, показывает типовые запросы для этой роли
- Плейсхолдер в поле ввода меняется в зависимости от роли
- Активный чип подсвечивается (голубой фон)

### 22. Клик по ⚙ открывает настройки помощника
- Кнопка ⚙ у каждого чипа
- Клик НЕ переключает активную роль, только открывает форму настроек в центре
- Форма содержит: название, описание, система-промпт
- Сохранить/Отмена (в центре, не в панели)

### 23. «+ свой» открывает форму «Новый помощник»
- Текстовая ссылка (не кнопка) внизу списка чипов
- Открывает форму в центре (не в панели)

### 24. Строка масштаба (Сцена/Глава/Диалог/Выделение)
- Под чипами: четыре кнопки/радиокнопки
- Выбранный масштаб подсвечивается
- Клик меняет контекст запроса

### 25. Выделение текста → масштаб «Выделение»
- Клик+выделение в редакторе (центр)
- Автоматически переключает масштаб на «Выделение» в правой панели
- Показывает цитату выделенного текста над полем ввода

### 26. Форма запроса внизу, диалог растягивается
- Диалог (сообщения): растягивающаяся область, скроллируется
- Поле ввода: прижато к нижнему краю панели
- Кнопка отправки: или Enter, или явная кнопка
- Ответы добавляются над полем (внутри диалога)

### 27. Строка контекста
- Над диалогом: текст типа «Текст этой сцены + Кодекс серии»
- Показывает какие источники используются для контекста

## Архитектура

### State в App.tsx
```typescript
const [activeAIRole, setActiveAIRole] = useState<string>('coauthor') // ID роли
const [aiScope, setAIScope] = useState<'scene' | 'chapter' | 'dialog' | 'selection'>('scene')

const [aiMessages, setAIMessages] = useState<Array<{ role: 'user' | 'assistant', content: string }>>([])
const [aiInput, setAIInput] = useState<string>('')
```

### Компонент AIPanel
Новый компонент `frontend/src/components/AIPanel.tsx`:
- Список чипов ролей (переключение, активный фон)
- Кнопки ⚙ (открывают форму в центре)
- Ссылка «+ свой»
- Строка масштаба (Сцена/Глава/Диалог/Выделение)
- Строка контекста
- Диалог (сообщения)
- Поле ввода
- Кнопка отправки или Enter

### Обработчики
- `handleSelectAIRole(roleId)`: смена активной роли, очистка диалога
- `handleAIScope(scope)`: смена масштаба запроса
- `handleAIMessage(message)`: отправка запроса на backend `/api/ai/query`
- `handleTextSelection(text)`: срабатывает при выделении текста в редакторе, автоматически меняет масштаб на 'selection'

### Backend (заглушка для MVP)
- POST `/api/ai/query` — принимает role, scope, context, message
- Возвращает ответ (пока что просто эхо или статичный ответ)
- Полная интеграция с моделями (GPT, Claude и т.д.) — Фаза 2

## Визуальные требования

- Активный чип: `--selected-bg` (голубой)
- Неактивный чип: `--surface-2`
- Ссылка «+ свой»: текстовая, как в мокапе
- Диалог: `--surface` фон, сообщения юзера справа, ассистента слева
- Поле ввода: прижато к низу, resize: none, ограничение по высоте

## Тестирование

1. Клик на чип → активен, диалог очищен, плейсхолдер изменился
2. Клик на ⚙ → форма настроек в центре
3. Клик на «+ свой» → форма нового помощника в центре
4. Клик на масштаб → переключение, контекст обновился
5. Выделение текста в редакторе → масштаб автоматически «Выделение», цитата видна
6. Ввод текста + Enter → отправка, сообщение появилось в диалоге
7. Ответ от AI → сообщение ассистента над полем ввода
8. Скролл диалога — не прерывает работу ввода
