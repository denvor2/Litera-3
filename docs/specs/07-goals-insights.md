# Модуль «Цели и статистика» — Фаза 2 (черновая спека)

Источник: п. 3.7 исходного ТЗ.

Расчёт а.л. (авторский лист = 40 000 знаков с пробелами) и страниц (1800 знаков) уже частично нужен в Фазе 0 (счётчики на карточке сцены, см. 01-manuscript.md) — используется общая утилита подсчёта, не дублировать в модуле статистики (Архитектор проверяет это отдельно, см. DOD.md п.2).

Открытый вопрос: цель по объёму — план на всю книгу (12 а.л.) считается от суммы всех сцен или от отдельно заданного плана, который автор вводит вручную? Второе — иначе прогресс "65%" не имеет смысла без независимо заданной цели.
