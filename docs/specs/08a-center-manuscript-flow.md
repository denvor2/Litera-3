# Спринт 8a — Архитектура центра: непрерывный поток рукописи

## Задача
Переделать центральную зону с одно-сценового редактора на **непрерывный поток** — интерактивное дерево-документ, в котором:
- Все главы и сцены текущей книги видны в едином потоке
- Сцены разворачиваются/сворачиваются
- Нажатие на главу/сцену скроллит к ней, разворачивает или только сворачивает (в зависимости от типа)
- Тумблер «Развернуть всю книгу» / «Свернуть до одной открытой»
- Все виды центра (редактор / карточка Кодекса / карточка книги / настройки) переключаются **без закрытия** левой и правой зон

## Поведение (из UI-VERIFICATION-CHECKLIST, пп. 10–27)

### 10. Клик по сцене в дереве (левый сайдбар)
- Сворачивает предыдущую развёрнутую сцену
- Разворачивает выбранную сцену
- Скроллит к ней
- Фон сцены — `--selected-bg` (голубой)

### 11. Клик по главе в дереве
- **Скроллит к разделителю главы** (не трогает развёрнутость сцен внутри главы)
- Глава получает фон `--selected-bg` (голубой) пока фокус на ней

### 12. Тумблер «Развернуть всю книгу» / «Свернуть до одной»
- Кнопки над потоком: Развернуть / Свернуть
- Развернуть: все сцены видны текстом
- Свернуть: одна открытая сцена (та, что была выбрана в фокусе); остальные — коллапсированы (видны только заголовки)

### 13. Статус сцены редактируется инлайн
- `<select>` со статусами (`draft/editing/done`) **внутри потока**, рядом с названием сцены
- Клик на select → PUT `/api/scenes/:sceneId` с новым статусом
- Живое обновление точки-индикатора (цвет по статусу)

### 14. POV, локация, переименование, целевой объём
- Только через форму настроек сцены (✎ в левом сайдбаре)
- Форма открывается в центре (за счёт переключения вида, не в отдельной модалке)

### 15. Кликабельность упоминаний (`.mention`)
- Клик по подсвеченному названию Кодекса открывает карточку Кодекса **в центре**
- Не закрывает левую/правую зоны

### 16. Переключение видов центра без закрытия панелей
- Один механизм `showCenterView` (или аналог): `'manuscript' | 'codex-card' | 'book-card' | 'project-card' | 'settings-scene' | 'settings-chapter' | 'settings-project' | 'guide' | 'ai-settings'`
- Редактор рукописи → клик ✎ → форма настроек → клик ← назад → редактор (всё в центре)
- Редактор → клик на упоминание → карточка Кодекса → клик «← Назад» → редактор потока

### 17. Форма настроек: «← Назад» + Отмена/Сохранить
- Кнопка «← Назад» возвращает в предыдущий вид центра
- Отмена: закрыть форму, вернуться (без сохранения)
- Сохранить: PUT запрос + обновить поток + вернуться

### 18. Карточка Кодекса: редактируемые поля + блок «появляется в сценах»
- Поля: название, атрибуты (для персонажа: внешность/характер/цель; для локации: описание)
- Блок «Появляется в сценах»: список сцен, в которых упоминается эта сущность (проверка по `SceneEntityLink`)
- Клик на сцену в этом списке → развернуть рукопись, скролл к сцене, развернуть сцену, подсветить упоминание

## Архитектурные решения

### Механизм `showCenterView`
В `App.tsx` добавить state:
```typescript
type CenterViewType = 'manuscript' | 'codex-card' | 'book-card' | 'project-card' | 
                      'settings-scene' | 'settings-chapter' | 'settings-project' | 
                      'guide' | 'ai-settings'
const [centerView, setCenterView] = useState<CenterViewType>('manuscript')
const [centerViewContext, setCenterViewContext] = useState<any>(null) // для передачи данных (какая сцена, какой кодекс и т.д.)
const [viewStack, setViewStack] = useState<CenterViewType[]>(['manuscript']) // стек для «← Назад»
```

Функция переключения:
```typescript
const showCenterView = (view: CenterViewType, context?: any) => {
  setViewStack([...viewStack, centerView])
  setCenterView(view)
  setCenterViewContext(context)
}

const goBack = () => {
  if (viewStack.length > 0) {
    const prev = viewStack[viewStack.length - 1]
    setViewStack(viewStack.slice(0, -1))
    setCenterView(prev)
  }
}
```

### Компонент `ManuscriptFlow`
Новый компонент (или расширение `SceneEditor`):
- Принимает: текущую книгу, выбранную сцену, обработчики (onSelectScene, onStatusChange, onEdit)
- Рендерит: дерево глав с развёртываемыми сценами
- На каждую развёрнутую сцену помещает редактор TipTap (или просто содержимое + кнопка редактирования)
- Инлайн select статуса
- Над потоком: кнопки Развернуть/Свернуть

### Подсветка упоминаний
В `SceneEditor` (или `ManuscriptFlow`):
- При рендере сцены парсим `body` (TipTap JSON)
- Для каждого упоминания имени Кодекса (точное совпадение) оборачиваем в `<span className="mention" onClick={() => showCenterView('codex-card', { entryId })}>…</span>`
- Стиль `.mention` из мокапа: оранжевый (accent) фон или border

## Ограничения и заглушки

- **Морфология:** Только точные совпадения (без склонений) — Фаза 2
- **SceneEntityLink:** используем для блока «Появляется в сценах», но UI-инструмента для создания ссылок нет (см. Фаза 2)
- **Версионирование:** остаётся внутри `VersionHistory` компонента, но механизм может быть переделан позже

## Тестирование

1. Открыть книгу, развернуть главы/сцены
2. Клик на сцену → скролл, разворот, выделение
3. Клик на главу → скролл к разделителю, без разворота
4. Тумблер Развернуть → все сцены видны
5. Тумблер Свернуть → одна сцена открыта
6. Инлайн select статуса → PUT запрос, обновление точки-индикатора
7. Клик на упоминание → карточка Кодекса в центре
8. ← Назад в карточке → вернуться в поток
9. ✎ сцены → форма настроек в центре (не закрывает левую/правую)
10. ← Назад в форме → вернуться в поток
11. Счётчик слов: обновляется при разворачивании/сворачивании сцен (сумма видимых)

1. SceneEditor использует `writeMode` параметр, но кнопка не подключена → убрать или реализовать отдельно в Фазе 1
