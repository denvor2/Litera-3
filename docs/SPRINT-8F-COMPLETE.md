### 3. Экспорт в гамбургер меню (3 варианта)

- **Файлы:** App.tsx, handleExport, меню
- **Удалено:** ExportButton из topbar
- **Тип:** UX улучшение

### 4. Иконка полноэкрана улучшена
- **Изменение:** ⛺/⛔ заменены на ⊞/⊟ (более подходящие иконки полноэкрана)
- **Файлы:** App.tsx, topbar button
- **Тип:** Polish

### 5. Корзина — иконки восстановления и удаления
- **Изменение:** Добавлены иконки ↩️ (восстановить) и 🗑️ (удалить) с подтверждением
- **API endpoints:** DELETE `/api/trash/{type}/{id}/permanent`
- **Файлы:** Sidebar.tsx, App.tsx (backend handlers)
- **Тип:** Функциональность

### 6. Заметки — создание как отдельная сущность
- **Изменение:** Заметки создаются как отдельные сущности через форму, как Кодекс и Книги
- **БД:** Новая таблица `notes` с полями: id, projectId, title, content, deletedAt, timestamps
- **API endpoints:**
  - GET `/api/notes/:projectId` — получить все заметки проекта
  - POST `/api/notes` — создать заметку
  - PUT `/api/notes/:noteId` — обновить заметку
  - DELETE `/api/notes/:noteId` — удалить заметку (soft delete)
- **Файлы:** 
  - Backend: index.ts (endpoints), schema.prisma (миграция)
  - Frontend: App.tsx (форма), types.ts (Note интерфейс)
- **Миграция:** 20260723075741_add_notes_table
- **Тип:** Новая функциональность

### 7. Статистика подвала — обновление в реальном времени
- **Изменение:** Слова, символы, авторские листы и страницы пересчитываются из текста в реальном времени, а не из сохраненного wordCount
- **Формула:** `wordCount = sceneText.split(/\s+/).filter(w => w.length > 0).length`
- **Файлы:** App.tsx, статистика вычисления
- **Тип:** Bug fix
