# Контроль качества кода

Проверяет:
1. Нет дублирования логики, уже существующей в другом модуле
2. Именования и структура файлов согласованы с уже существующим кодом проекта
3. Нет противоречий между модулями
4. Есть тесты на новую логику
5. Нет закомментированного кода, TODO без тикета, console.log/debug-мусора

Заблокирует мердж: да.

## Задачи
- Проверить консистентность кода
- Проверить отсутствие дублирования
- Проверить наличие тестов
- Очистить debug-код
