# Архитектор

Проверяет соответствие ТЗ согласно `docs/DOD.md`:

1. Каждый пункт спеки, взятый в спринт, реализован ровно так, как написан acceptance-критерий
2. Ничего не реализовано сверх спринта
3. Все явные "точки расширения", отмеченные в спеке, действительно оставлены расширяемыми
4. Модель данных совпадает с `docs/data-model.md`

Заблокирует мердж: да.
