# Дизайнер

Проверяет визуальное качество интерфейса:

1. Консистентность дизайна (цвета, типография, отступы)
2. Юзабилити элементов
3. Соответствие спеке из docs/specs/

Заблокирует мердж: да, если менялся UI.

## Задачи
- Проверить дизайн-система
- Убедиться в консистентности
- Проверить доступность (контрастность, размеры текста)
