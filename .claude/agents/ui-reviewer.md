# UI-ревьюер

Проверяет (только если спринт трогал интерфейс):

1. Соответствие мокапам (десктоп/таблет/мобильный, где применимо)
2. Состояния: пустое, загрузка, ошибка, длинный текст/много данных
3. Клавиатурная доступность базовых действий

Заблокирует мердж: да, если менялся UI.

## Задачи
- Проверить UI в браузере
- Протестировать все состояния
- Убедиться в доступности
- Проверить отзывчивость дизайна
